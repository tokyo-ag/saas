# 機能要件

## 認証・アカウント

| ID | 要件 |
| --- | --- |
| FR-AUTH-001 | 主催者はメール・パスワードで登録できる |
| FR-AUTH-002 | 登録時にメール確認を要求できる |
| FR-AUTH-003 | 主催者はログインできる |
| FR-AUTH-004 | 主催者はパスワードリセットできる |
| FR-AUTH-005 | 主催者はLINE Login経由で登録導線に入れる |
| FR-AUTH-006 | 機密設定変更時は再認証トークンを要求できる |
| FR-AUTH-007 | JWTで管理APIを保護する |

## テナント管理

| ID | 要件 |
| --- | --- |
| FR-TENANT-001 | テナントは名前、説明、公開コード、テーマカラー、アイコンを持つ |
| FR-TENANT-002 | テナントはLINE Channel情報、LIFF ID、Messaging APIトークンを設定できる（PROプラン限定） |
| FR-TENANT-003 | テナントはStripe公開鍵、秘密鍵、Webhook secretを設定できる（PROプラン限定） |
| FR-TENANT-004 | テナントはプラン `free` / `standard` / `pro` を持つ |
| FR-TENANT-005 | テナントは論理削除、BAN状態を持つ |
| FR-TENANT-006 | テナントごとのダッシュボード統計、成長データ、活動履歴を表示できる |

## イベント管理

| ID | 要件 |
| --- | --- |
| FR-EVENT-001 | 主催者はイベントを作成、編集、削除できる |
| FR-EVENT-002 | イベントは下書き、受付中、受付終了の状態を持つ |
| FR-EVENT-003 | イベントは日時、終了日時、場所、場所URL、説明、定員、性別別定員を持てる |
| FR-EVENT-004 | イベントは参加費、性別別価格、支払い要否、支払いタイミングを持てる |
| FR-EVENT-005 | イベントは画像、アイコン、カテゴリ、タグを持てる |
| FR-EVENT-006 | 主催者は予約者一覧を確認できる |
| FR-EVENT-007 | 主催者はイベント予約者をCSV出力できる |
| FR-EVENT-008 | 主催者はイベント参加者へLINE/アプリ内メッセージを送れる |
| FR-EVENT-009 | 主催者はリマインドを手動/スケジュールで送れる |
| FR-EVENT-010 | 主催者はチェックインを記録できる |

## 予約

| ID | 要件 |
| --- | --- |
| FR-RES-001 | 参加者はLIFFからイベント予約できる |
| FR-RES-002 | 予約時に名前、学年、性別を登録/更新できる |
| FR-RES-003 | 定員内なら `reserved` になる |
| FR-RES-004 | 定員超過時は `waitlisted` とし、順番を保持できる |
| FR-RES-005 | 決済が必要な場合は `waiting_payment` を扱える |
| FR-RES-006 | 参加者は予約をキャンセルできる |
| FR-RES-007 | 主催者は予約状態を `reserved` / `attended` / `cancelled` 等に更新できる |

## LIFF参加者体験

| ID | 要件 |
| --- | --- |
| FR-LIFF-001 | 参加者はテナントのイベント一覧を見られる |
| FR-LIFF-002 | 参加者はイベント詳細、残席、価格、レビューを見られる |
| FR-LIFF-003 | 参加者はプロフィールを登録・編集できる |
| FR-LIFF-004 | 参加者は通知一覧を確認できる |
| FR-LIFF-005 | 参加者は他メンバーとコネクションを作れる |
| FR-LIFF-006 | 参加者同士でメッセージできる |
| FR-LIFF-007 | 参加者は管理者へメッセージできる |
| FR-LIFF-008 | 参加者はCOMIUサポートへメッセージできる |
| FR-LIFF-009 | 参加者はイベント終了後レビューを投稿できる |

## メンバー管理

| ID | 要件 |
| --- | --- |
| FR-MEMBER-001 | 主催者はメンバー一覧を検索・確認できる |
| FR-MEMBER-002 | 主催者はメンバー詳細と予約履歴を確認できる |
| FR-MEMBER-003 | 主催者はメンバーをブロック/解除できる |
| FR-MEMBER-004 | 主催者はメンバー一覧をCSV出力できる |
| FR-MEMBER-005 | 主催者はLINEプロフィール同期を実行できる |

## 公開ページ・SEO

| ID | 要件 |
| --- | --- |
| FR-PUBLIC-001 | トップページに公開イベントと注目団体を表示する |
| FR-PUBLIC-002 | 公開イベントページ `/e/:tenantCode/:eventId` を提供する |
| FR-PUBLIC-003 | 公開団体ページ `/clubs/:tenantCode` を提供する |
| FR-PUBLIC-004 | スポーツカテゴリページ `/sports/:category` を提供する |
| FR-PUBLIC-005 | 活用事例ページ、料金ページ、規約、プライバシーポリシーを提供する |
| FR-PUBLIC-006 | canonical、OGP、Twitter Card、JSON-LDを出力する |
| FR-PUBLIC-007 | sitemap.xml と robots.txt を提供する |
| FR-PUBLIC-008 | 管理画面/LIFF/ログイン系はnoindexにする |

## 課金・決済

| ID | 要件 |
| --- | --- |
| FR-BILL-001 | テナントはSaaSプラン課金Checkoutを開始できる |
| FR-BILL-002 | Stripe Webhookによりプラン状態を更新できる |
| FR-BILL-003 | イベント決済用にテナント別Stripeキーを保存できる |

## スーパー管理

| ID | 要件 |
| --- | --- |
| FR-SA-001 | スーパー管理者はテナント一覧を確認できる |
| FR-SA-002 | スーパー管理者はテナントを作成、更新、停止、復元、BAN、削除できる |
| FR-SA-003 | スーパー管理者はテナントへ代理ログインできる |
| FR-SA-004 | スーパー管理者はLINEユーザーをBAN/解除できる |
| FR-SA-005 | スーパー管理者はサポートスレッドを確認・返信できる |
