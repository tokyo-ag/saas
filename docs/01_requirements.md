# 要件定義

## 背景

小規模コミュニティやスポーツサークルでは、イベント告知、予約受付、参加者管理、リマインド、キャンセル待ち、問い合わせ対応が LINE、スプレッドシート、個別DMなどに分散しやすい。COMIU はこれらを一元化し、主催者の運用負荷を下げ、参加者にはLINE上で迷わず予約できる体験を提供する。

## 目的

- 主催者がイベント管理と参加者募集を簡単に行えること
- 参加者がLINEからイベントを探し、予約し、通知を受け取れること
- 公開ページから検索流入を獲得できること
- COMIU運営がテナント、課金、BAN、サポートを管理できること

## スコープ

### 対象

- Web管理画面
- LINE LIFF参加者画面
- 公開SEOページ
- Backend API
- DB設計
- LINE / Stripe / Gmail / Blob 連携
- スーパー管理画面

### 対象外

- ネイティブアプリ
- 複数管理者ロールの細分化
- 会計・請求書の詳細管理
- 高度なCRM/MA機能
- LINE公式アカウント作成代行

## 成功条件

- 主催者がイベントを作成し、公開できる
- 参加者がLIFFから予約・キャンセルできる
- 定員超過時にキャンセル待ちになる
- 主催者が予約者一覧を確認し、CSV出力できる
- 公開イベントページが検索エンジンにindex可能である
- 管理系ページはnoindexである
- テナントデータが混在しない
- Stripe/Gmail/LINEの機密値が外部に漏れない

## 利用シナリオ

### 主催者

1. COMIUに登録する
2. 団体情報とLINE/Stripe設定を行う
3. イベントを作成する
4. 公開URLやLINEで参加者を募集する
5. 予約者を確認し、必要に応じてメッセージやリマインドを送る
6. 当日チェックインする
7. 終了後レビューを確認し、公開する

### 参加者

1. 公開ページまたはLINEからイベントを開く
2. LIFFでLINEプロフィールを連携する
3. プロフィール情報を入力する
4. イベントを予約する
5. 予約状況・通知・管理者メッセージを確認する
6. 必要に応じてキャンセル、レビュー投稿、友達追加を行う

### COMIU運営

1. スーパー管理者でログインする
2. テナント一覧を確認する
3. 問題のあるテナントやLINEユーザーを停止/BANする
4. サポート問い合わせに返信する
5. 必要に応じてテナントに代理ログインする

## 制約

- 参加者認証はLINE LIFF前提
- テナント識別は内部IDと公開用 `code` の併用
- DBはPostgreSQL
- ORMはPrisma
- フロントはNext.js App Router
- バックエンドはNestJS
